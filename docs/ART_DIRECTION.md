# キャラクター造形のブラッシュアップ方針

現在のGeometry製モデルは、カメラ・群集密度・攻撃範囲・役割の判別を試すための仮モデル。
デフォルメを完成形として固定しない。ユーザー提供の参考画像を、重厚な金属の仏像と
赤黒い甲冑の軍勢という方向性の基準とする。

## 次のモデル制作で合わせる点

- 仏像：丸い部品の組み合わせから、写実寄りの顔、螺髪、衣の重いひだ、指・掌へ。
- 材質：一様に明るい金色から、鋳造した金属の暗部・摩耗・部分的な金箔へ。
- 体格：落武者より大きい存在感を保ちつつ、頭・胴・手足を人体に近い比率へ調整する。
- 武器と光背：接続部や装飾を作り込み、振った際に重さを感じる錫杖にする。
- 敵：雑兵、武者、精鋭、中ボスを、体格だけでなく兜・肩鎧・武器の輪郭で判別できるようにする。
- 動作：踏み込み、腰と肩のひねり、振り抜き、戻しを骨格アニメーションでつなぐ。

## 実装上の移行

1. 仏像一体をGLB形式の専用モデルへ置き換え、走る・通常3段・強攻撃・仏技・回避・被弾を確認する。
2. 現在のプレイヤー位置・向き・攻撃進行度を新しい描画へ渡し、戦闘判定と分離した構成を保つ。
3. 敵は同じ骨格の装備違いから作る。70体以上を個別の高密度SkinnedMeshで描くと負荷が上がるため、
   GPUで共有するアニメーション、遠距離LOD、影の距離制限などを合わせて検証する。
4. 仮モデルと同じ入力で比較し、攻撃の視認性・当たり判定との一致・フルHDの描画速度を維持する。

今回の戦場・敵種追加では、敵の色・大きさ・HP表示の違いを先に実装した。
専用モデルと骨格アニメーションの制作・導入は、まだ完了していない。
